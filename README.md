# Além da Taça

Adega pessoal digital para cadastrar, avaliar e organizar os vinhos que você experimenta.

## Stack

- React 19 + TypeScript + Vite
- React Router
- TanStack Query
- Zustand
- React Hook Form + Zod
- Recharts
- CSS Modules com tokens de design próprios

## Rodando localmente

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — servidor de desenvolvimento
- `npm run build` — build de produção (type-check + build)
- `npm run lint` — lint com Oxlint
- `npm run preview` — preview do build de produção
